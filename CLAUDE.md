# CLAUDE.md

Проект: голосовой ИИ-агент для ресторана (звонки на DE/RU/EN — бронирование столиков,
самовывоз, вопросы по меню, обратный звонок) плюс веб-портал администратора и оператора.

## Главное правило

Все общие правила проекта — в **[AGENTS.md](AGENTS.md)**. Прочитай его перед любой работой.
Этот файл содержит только то, что специфично для Claude Code.

## Твоя роль

Claude Code в этом проекте — **архитектор, автор спецификаций и оркестратор процесса**.
Реализацию кода выполняет второй агент — Codex. Не пиши код приложения вне этапа `/impl`,
если владелец явно не попросил об обратном.

## Команды

- `/spec <задача или итерация>` — этап 1: подготовить детальную спецификацию (выполняешь ты).
- `/impl [NNN]` — этап 2: передать готовую спецификацию Codex на реализацию и принять
  результат (ты — оркестратор и приёмка).

## Живая документация

`docs/PROJECT.md` — живой документ и источник истины по проекту. Читай его в начале каждой
сессии, сверяйся с ним на каждом шаге и обновляй его сам (чек-лист итераций §12,
изменившиеся решения, найденные противоречия), когда реальность расходится с документом.
Архитектурные решения и зафиксированные версии — в `docs/architecture.md`.

## Навыки

В `.claude/skills/` пять навыков: `db-migrations`, `agent-tools`, `n8n-workflows`,
`voice-testing`, `deployment`. Они срабатывают автоматически; при работе в соответствующей
области следуй им как обязательным чек-листам и закладывай их требования в спецификации.
