# Проверка голосового агента

Реальные звонки, реальные API и вызовы LLM в автотестах запрещены — всё перечисленное
здесь оформляется как инструкции ручного тестирования (`specs/NNN-<slug>/manual-tests.md`)
и выполняется человеком. Автотестами покрывается обвязка: роутинг TTS, форматирование,
валидация, i18n-ресурсы.

## Базовые сценарии — A–F из docs/PROJECT.md §1.2

A. Бронь на немецком. B. Занятое время → до трёх альтернатив. C. Самовывоз на русском
со сменой языка. D. Вопрос по меню (веган → только `is_vegan` и `is_available`).
E. Обратный звонок (банкет). F. Тестовый звонок из портала (сущности помечены как тестовые).

## Чек-лист по каждому языку (de, ru, en)

- [ ] Объявление об ИИ звучит первой фразой, до сбора любых данных.
- [ ] Распознавание и ответ на языке клиента; переключение языка в середине разговора
      по правилу двух реплик (PROJECT.md §4.1) — одно иностранное слово не переключает.
- [ ] Филлер-фраза перед каждым вызовом инструмента.
- [ ] Даты, время и цены произносятся корректно для языка (`format_time` / `format_price`).
- [ ] Реплики агента укладываются в одно-два предложения.

## Сценарные проверки

- [ ] Агент зачитывает состав заказа и сумму ДО оформления и ждёт подтверждения.
- [ ] Номер заказа диктуется дважды и совпадает с базой.
- [ ] Агент не выдумывает блюда, которых нет в меню.
- [ ] При недоступности n8n или Mistral — извинение и предложение обратного звонка,
      а не молчание или обрыв.
- [ ] Задержка ответа: < 1,5 с без инструмента, < 2 с с инструментом (PROJECT.md §3.3).
- [ ] Ничего не записывается: ни аудио, ни транскриптов (транскрипт на экране
      тестового звонка не сохраняется).

## Формат инструкции ручного теста

Для каждого пункта: предусловия (что настроить/запустить) → шаги (что и на каком языке
сказать) → ожидаемое поведение → что записать в результаты. Инструкция должна быть
выполнимой без чтения кода.
