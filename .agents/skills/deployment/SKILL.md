# Адаптер правил деплоя

Перед любым действием прочитать канонический чек-лист
`../../../.claude/skills/deployment/SKILL.md` полностью и следовать ему как обязательному. Затем
свериться с `AGENTS.md` и актуальными разделами `docs/PROJECT.md`; они имеют
приоритет при расхождении.

Не копировать правила в другие файлы: `.claude/skills/deployment/SKILL.md` остаётся единым
проектным источником для Claude Code и Codex.
