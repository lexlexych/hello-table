# specs/ — архив спецификаций

**Папка заморожена 18.08.2026.** Новые файлы сюда не добавляются, статусы в существующих
не меняются. Актуальный порядок работы — `AGENTS.md` §2: задача выполняется одним циклом,
отдельный документ-спецификация не пишется.

Здесь лежат спецификации и отчёты прежнего двухэтапного процесса (`/spec` → `/impl`). Они
сохранены как контекст: почему код итераций 2–4, 9 и 11 выглядит именно так, и какие ручные
проверки к нему прилагаются.

```
specs/NNN-<slug>/
├── spec.md           # спецификация
├── report.md         # отчёт о реализации
└── manual-tests.md   # инструкция ручного тестирования
```

| Спека | Итерация | Состояние на момент заморозки |
|---|---|---|
| `001-db-schema-and-functions` | 2 | реализована |
| `002-agent-prototype-de` | 3 | реализована частично, итерация не закрыта |
| `003-multilingual-tts-router` | 4 | реализована, отчёта нет |
| `004-portal-test-call` | 9 и 11 частично | реализована |

Ни одна не была подтверждена ручными проверками владельца. Их непройденный список перенесён
реестром в [docs/manual-tests.md](../docs/manual-tests.md) — там же отмечается выполнение.
Статусы во фронтматтере `spec.md` остаются историческими и больше ничего не означают.
