# Ручная проверка спеки 004 — портал и тестовый звонок

Выполняется человеком: нужны реальные ключи Mistral и ElevenLabs, микрофон и внешняя сеть —
всё это автотестам запрещено (AGENTS.md §4).

Инструкция самодостаточна: читать код не нужно. Результаты записывайте в раздел 7.

## 0. Что понадобится

- Node.js 24, pnpm, Docker Desktop (запущен), рабочий микрофон и колонки или наушники.
- Браузер Chrome или Edge.
- Ключ Mistral с доступом к Voxtral Realtime и Mistral Large 3.
- Ключ ElevenLabs, идентификатор голоса и имя multilingual-модели из вашей панели.
- Около 15 минут; первый запуск дольше — качаются модели VAD и turn detector.

**Наушники лучше колонок.** Эхоподавление в браузере включено, но при громких колонках агент
слышит сам себя и перебивает вас.

## 1. Подготовка окружения

### 1.1 Файл `.env`

Скопируйте `.env.example` в корневой `.env`, если его ещё нет, и заполните:

```
MISTRAL_API_KEY=<ваш ключ>
STT_MODEL=voxtral-mini-transcribe-realtime-2602
LLM_MODEL=mistral-large-latest

ELEVENLABS_API_KEY=<ваш ключ>
ELEVENLABS_VOICE_ID=<id голоса>
ELEVENLABS_MODEL=<multilingual-модель из панели ElevenLabs>

LIVEKIT_URL=ws://localhost:7880
LIVEKIT_API_KEY=devkey
LIVEKIT_API_SECRET=secret

LOG_LEVEL=warn
```

`LOG_LEVEL=warn` обязателен: на `info` LiveKit Agents 1.6.4 печатает текст ваших реплик в
консоль. `devkey` / `secret` — значения локального `livekit --dev`, в продакшн они не идут.

Секрет подписи cookie сгенерируйте и вставьте в `SESSION_SECRET`:

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

### 1.2 Пароли портала

Дважды выполните команду — для администратора и для оператора:

```powershell
pnpm portal:hash
```

Команда спросит пароль (ввод не отображается), попросит повторить и напечатает bcrypt-хеш.
Вставьте первый хеш в `ADMIN_PASSWORD_HASH`, второй — в `OPERATOR_PASSWORD_HASH`.
Логины оставьте `admin` и `operator` или задайте свои в `ADMIN_USERNAME` / `OPERATOR_USERNAME`.

**Ожидаемо:** пароль на экране не появляется; при вводе короче 12 символов или несовпадении
повтора команда отказывается печатать хеш.

### 1.3 Модели агента

Один раз, требует сети (несколько десятков мегабайт):

```powershell
pnpm agent:download-files
```

## 2. Запуск

Три отдельных окна терминала, по одной команде в каждом.

```powershell
pnpm livekit:up
```

```powershell
pnpm agent:dev
```

```powershell
pnpm portal:dev
```

**Ожидаемо:**

- контейнер LiveKit становится `healthy`;
- воркер агента печатает регистрацию и ждёт задания, ошибок конфигурации нет;
- портал сообщает `http://localhost:3000`.

**Если агент падает сразу** — прочитайте текст: он перечисляет имена незаполненных
переменных окружения (значений там нет намеренно). Заполните и перезапустите.

## 3. Вход и роли

Откройте **`http://localhost:3000`**. Именно `localhost` — по адресу вида `http://192.168.x.x`
браузер не даст доступ к микрофону.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 3.1 | Открыть `http://localhost:3000` | Переброс на `/login`, форма входа |
| 3.2 | Ввести логин `admin` и **неверный** пароль | Сообщение «Неверный логин или пароль», вход не выполнен |
| 3.3 | Ввести `admin` и верный пароль | Открывается «Тестовый звонок», в шапке `admin` и бейдж `admin` |
| 3.4 | Нажать «Выйти» | Возврат на форму входа |
| 3.5 | Войти как `operator` | Тот же экран, в шапке бейдж `operator` |

## 4. Проверки защиты

Выполнять в отдельном окне PowerShell, портал при этом запущен.

**4.1 API без сессии отдаёт 401:**

```powershell
try { Invoke-WebRequest -Method POST http://localhost:3000/api/test-call/token -UseBasicParsing } catch { $_.Exception.Response.StatusCode.value__ }
```

Ожидаемо: печатается `401`.

**4.2 Страница без сессии уводит на вход.** Откройте `http://localhost:3000/test-call` в
приватном окне браузера. Ожидаемо: форма входа.

**4.3 Rate limit срабатывает на шестой попытке:**

```powershell
1..6 | ForEach-Object { try { Invoke-WebRequest -Method POST http://localhost:3000/api/login -ContentType 'application/json' -Body '{"username":"admin","password":"wrong"}' -UseBasicParsing } catch { "$_ -> " + $_.Exception.Response.StatusCode.value__ } }
```

Ожидаемо: первые пять ответов `401`, шестой `429`. После этого подождите 15 минут или
перезапустите `pnpm portal:dev`, иначе вход будет закрыт и вам.

## 5. Тестовый звонок — главное

Войдите админом, откройте «Тестовый звонок».

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 5.1 | Нажать «Позвонить» | Браузер просит доступ к микрофону — разрешить |
| 5.2 | Дождаться соединения | Статус «Идёт разговор — говорите в микрофон» |
| 5.3 | Слушать | Агент **сам заговорит первым**: «Hinweis: Sie sprechen mit einem KI-gestützten Sprachassistenten. Guten Tag, wie kann ich Ihnen helfen?» — объявление об ИИ обязано звучать до всего остального (§11.1) |
| 5.4 | Смотреть на экран | Текст того, что произнёс агент, появляется в транскрипте |
| 5.5 | Спросить по-немецки, например «Wann haben Sie geöffnet?» | Ваша фраза появляется в транскрипте как «Вы»; агент отвечает **голосом**, одна-две короткие фразы |
| 5.6 | Спросить «Ich möchte einen Tisch reservieren» | Агент честно говорит, что бронирование пока недоступно, и не выдумывает подтверждение |
| 5.7 | Сделать паузу в середине фразы | Агент не перебивает на паузе внутри предложения |
| 5.8 | Нажать «Завершить» | Разговор прекращается, статус «Звонок не начат» |
| 5.9 | Перезагрузить страницу | Транскрипт пуст — он нигде не сохраняется |
| 5.10 | Выйти, войти оператором, повторить 5.1–5.5 | Работает так же |

**Если через 12 секунд появилось «Агент не вошёл в комнату»** — воркер не запущен или упал.
Посмотрите окно `pnpm agent:dev`.

**Если агент вошёл, но молчит** — проверьте в окне агента ошибки Mistral или ElevenLabs
(неверный ключ, неизвестное имя модели или голоса).

## 6. Замеры, которые нужно записать

После «Завершить» окно `pnpm agent:dev` печатает числовую сводку сессии: задержки p50/max и
`rssBytes`. **Это давно висящие пункты PROJECT.md §3.3 и §8.1** — перенесите значения в
`docs/architecture.md`.

Отдельно на слух оцените п. 5.5: похоже ли на разговор, укладывается ли ответ примерно в
секунду. Это приёмка итерации 3 (§12).

## 8. Приборка

```powershell
pnpm livekit:down
```

Окна агента и портала закрываются `Ctrl+C`. Ничего удалять не нужно: звонок не создаёт
записей ни в базе, ни на диске.
