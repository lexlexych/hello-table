# Runbook — эксплуатация

Заполняется в итерации 15 (docs/PROJECT.md §12); отдельные разделы дополняются раньше,
по мере появления инфраструктуры (деплой — итерация 12, SIP — итерация 13).

Планируемые разделы:

- Запуск и остановка системы, порядок поднятия контейнеров
- Health-checks и что смотреть при инциденте
- Бэкапы: расписание, проверка восстановления
- Обновление зависимостей и образов
- Мониторинг: память, steal time, задержка ответа агента
- Типовые инциденты: недоступность Mistral / n8n / SIP-транка
