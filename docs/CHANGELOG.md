## 20.08.2026 — Portal API для облачных Telegram-workflow n8n

**Что сделано:** облачные Telegram-workflow больше не подключаются к PostgreSQL напрямую.

## 20.08.2026 — Агент входит в комнату: Silero VAD перенесён в prewarm

**Что сделано:** `silero.VAD.load()` вызывался внутри `entry`, то есть во время звонка.
Инициализация нативного onnxruntime блокирует event loop процесса джоба, тот перестаёт
отвечать на пинги родителя, и фреймворк убивает его по `ORPHANED_TIMEOUT` (15 секунд,
зашито в `@livekit/agents`) — в комнату агент не входил вовсе. Загрузка перенесена в
`prewarm(proc)`: она выполняется в простаивающем процессе до звонка. Дефект общий для
портала и сайта; выглядел случайным, потому что на прогретом файловом кеше модель успевала
загрузиться за 15 секунд.
