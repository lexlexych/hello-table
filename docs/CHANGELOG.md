# Журнал работ

Что именно менялось в проекте, задача за задачей, в обратном хронологическом порядке.
Запись обязательна для каждой задачи (`AGENTS.md` §2, шаг 6).

Разграничение с соседними документами (`AGENTS.md` §3): здесь — **что изменено**; обоснование
решения («почему так») идёт в `docs/architecture.md`, состояние проекта — в `docs/PROJECT.md`.

## Формат записи

```markdown
## ДД.ММ.ГГГГ — Название задачи

**Что сделано:** одно-два предложения по существу.
**Изменено:** файлы и области; отдельно — созданное и удалённое.
**Документация:** какие разделы docs обновлены и почему.
**Тесты:** команда и фактический результат, либо почему тесты не требовались.
**Ручные проверки:** ссылка на раздел `docs/manual-tests.md` или «нет».
**Итерация:** номер из `docs/PROJECT.md` §12 и что с ней стало, либо «вне итераций».
```

Записи до 18.08.2026 в этом файле отсутствуют: до перехода на одноэтапный процесс их роль
выполняли `specs/NNN-*/report.md` и отметки в чек-листе `docs/PROJECT.md` §12.
